## 🚀 Featured Projects

### 📱 [Attendance Control](https://github.com/MatheusMadureiraa/kotlin-attendance-control)

**Kotlin · Android Studio · Jetpack Compose**

Android application prototype for indoor attendance tracking using **BLE beacons**.

The project currently focuses on the Android application structure and UI implementation, including login screens, reusable UI components and mock data.

**Technologies:** Kotlin, Android, Jetpack Compose, Gradle Kotlin DSL.

---

### ⛓️ [BipTrust — TrustCode](https://github.com/MatheusMadureiraa/trustcode-solidity)

**Solidity · Ethereum · Hardhat · Ethers.js · React · IoT**

A Web3 escrow protocol designed for high-value rentals, combining **smart contracts, IoT and blockchain-based time tracking**.

The system uses a smart contract to manage deposits, rental periods, check-in/check-out events and financial settlement, with an IoT device acting as an oracle.

**Technologies:** Solidity, OpenZeppelin, Hardhat, Ethers.js, React, Vite, TailwindCSS, Ethereum.

🔗 [Smart Contract on Sepolia](https://sepolia.etherscan.io/address/0xE0696580c84e097Df56dfdE62Bb0E7e16397D45f)

---

### 💻 [Vallim Tornearia](https://github.com/MatheusMadureiraa/nodejs-tornearia)

**Node.js · Express · SQLite · Electron · Playwright**

Desktop management system designed for a local machine shop, providing offline operation and centralized management of customers, services and orders.

Features include CRUD operations, financial dashboards, PDF exports, backup and data restoration.

**Technologies:** Node.js, Express.js, SQLite, Electron, JavaScript, Playwright.

---

### 🏢 [SmartCondos](https://github.com/MatheusMadureiraa/JavaAndPostgreSQL-POO-SmartCondos)

**Java · PostgreSQL · MVC · UML**

A condominium management system developed using object-oriented programming principles and software engineering practices.

The project includes requirements documentation, UML diagrams, MVC architecture and a PostgreSQL database.

**Technologies:** Java, PostgreSQL, MVC, UML, Git.

---

### 🧪 [ServeRest API Tests](https://github.com/matheusmadureira/serrest-tests)

**Playwright · API Testing · Automation**

Automated API testing project focused on endpoint coverage, test organization and validation of RESTful services.

---

### 🧠 [Traveling Salesman Problem — Distributed & Parallel](https://github.com/MatheusMadureiraa/caixeiro-viajante-java)

**Java · Threads · Java RMI · Distributed Systems**

Implementation and performance analysis of three approaches to the Traveling Salesman Problem:

* Sequential execution
* Parallel execution using Java Threads
* Distributed execution using Java RMI

The project explores parallelism, distributed processing, scalability and performance analysis.
